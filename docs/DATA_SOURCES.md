# Data and AI sources

Checked on 24 October 2026.

| Need                                                      | Source                                                                                                                                                                                         | Limits                                                                                                                                                                                                                                         |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NSE / US stock prices, histories, indices and sector ETFs | Yahoo Finance public chart data                                                                                                                                                                | No broker sign-in. Quotes and completed candles have separate timestamps. Delays and missing candles remain visible.                                                                                                                           |
| NSE stock search                                          | Yahoo Finance public search                                                                                                                                                                    | Only NSE `.NS` results are offered; exact-symbol tracking remains available when search fails.                                                                                                                                                 |
| Crypto                                                    | Binance public daily candles and 24h ticker                                                                                                                                                    | Completed UTC spot candles; USDT differs from USD.                                                                                                                                                                                             |
| Global crypto                                             | CoinGecko global endpoint                                                                                                                                                                      | Provider snapshot of aggregate market cap and BTC dominance.                                                                                                                                                                                   |
| Company financials                                        | Yahoo annual fundamentals time series                                                                                                                                                          | Annual reported periods, not an earnings forecast or fair-value model.                                                                                                                                                                         |
| Screener research                                         | [Company pages](https://www.screener.in/)                                                                                                                                                      | Free external research links. [Official help](https://support.screener.in/article/28-export-screen-results) says no API and screen CSV exports are premium. No automatic ingestion.                                                            |
| News                                                      | Google News RSS                                                                                                                                                                                | Free entity-matched headlines and source links; sampled 7-day mention comparisons.                                                                                                                                                             |
| Public discussion                                         | Reddit public search RSS                                                                                                                                                                       | Selected investing communities; matched posts and title wording only. No account, comments, vote totals or unique-person count. Source failures stay unavailable.                                                                              |
| Search attention                                          | [Google Trends](https://support.google.com/trends/answer/4365533?hl=en)                                                                                                                        | Relative 0–100 interest via free website/CSV; limited current topics via public RSS. Topic traffic labels are not exact stock keyword counts. [Official API](https://developers.google.com/search/apis/trends) is alpha access, not connected. |
| Gemini                                                    | [Models](https://ai.google.dev/gemini-api/docs/models), [pricing](https://ai.google.dev/gemini-api/docs/pricing), [structured output](https://ai.google.dev/gemini-api/docs/structured-output) | Free/paid account access; current Flash options and paid Pro preview. Legacy 2.5 access can require earlier project use. The app cannot set or verify your account’s billing tier.                                                             |
| OpenAI                                                    | [Structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [pricing](https://developers.openai.com/api/docs/pricing)                           | OpenAI Platform API key, API billing/credit and model access required. Responses API with store=false. Subscription allowances are separate from API usage.                                                                                    |
| Groq                                                      | [Models](https://console.groq.com/docs/models), [free-plan limits](https://console.groq.com/docs/rate-limits), [structured outputs](https://console.groq.com/docs/structured-outputs)          | GPT-OSS 20B/120B and Qwen 3.8 27B preview. Free/paid account support; limits and available models can change.                                                                                                                                  |
| Ollama                                                    | [Installed models](https://docs.ollama.com/api/tags), [chat](https://docs.ollama.com/api/chat)                                                                                                 | Local endpoint on this Mac. Default Qwen3 8B; user-enabled installed chat models. Embedding-only and remote cloud tags excluded.                                                                                                               |
| Local AI                                                  | Installed Qwen3 8B / 14B through Ollama                                                                                                                                                        | Curated general models with source-grounded inputs, no validated finance-specialist claim.                                                                                                                                                     |

Private holdings and journal text are excluded from AI requests. No broker credentials or certificate setup is needed.
